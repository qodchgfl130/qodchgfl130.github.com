# PyQt5와 PyMySQL을 활용한 뉴스 검색 프로그램 상세 해설

이 프로그램은 **PyQt5**로 제작된 GUI와 **MySQL 데이터베이스**를 연동하여, 날짜 및 카테고리별 뉴스를 검색하고 상세 본문과 웹 URL로 연결해 주는 애플리케이션입니다.

---

## 1. 주요 클래스 및 구조

소스코드는 크게 메인 창을 담당하는 `MyWindow`와, 웹 링크 연결을 담당하는 서브 창 `MyWindow2` 두 개의 클래스로 구성되어 있습니다.

* **`MyWindow`**: 프로그램의 메인 화면입니다. DB 연결, 뉴스 목록 검색, 본문 출력을 담당합니다.
* **`MyWindow2`**: 선택한 뉴스의 원본 웹페이지(URL)로 이동할 수 있는 서브 화면입니다.

---

## 2. 주요 UI 위젯 매핑

| UI 위젯 종류 | 변수명 | 역할 및 설명 |
| :--- | :--- | :--- |
| **뉴스 목록 표** | `tableWidget` | DB에서 조회한 뉴스 목록(날짜, 언론사, 제목 등)을 표 형태로 출력 |
| **본문 출력창** | `textBrowser` | 목록에서 선택한 뉴스의 상세 본문 텍스트를 출력 |
| **카테고리 선택** | `comboBox` | 정치, 경제, 사회 등 검색할 뉴스 카테고리 선택 |
| **날짜 선택기** | `dateEdit` | 검색하고자 하는 뉴스의 날짜(`YYYYMMDD`) 지정 |
| **검색 버튼** | `serch` | 선택된 조건으로 MySQL DB 쿼리를 실행하는 버튼 |
| **바로가기 버튼** | `url` | 서브 창(`MyWindow2`)을 열어 원본 웹 링크를 열 수 있게 하는 버튼 |

---

## 3. 핵심 메서드(함수) 동작 과정

### ① `PushAndSerch(self)` — 뉴스 데이터 검색 및 표 출력
* **작동 순서**:
  1. `comboBox`에서 선택한 카테고리(`selected_category`)와 `dateEdit`에서 선택한 날짜(`dateStr`)를 조건으로 SQL 쿼리를 실행합니다.
  2. 조회 결과가 없을 경우 `QMessageBox.warning`을 띄워 안내합니다.
  3. 가져온 데이터를 `tableWidget`에 한 줄씩 채워 넣습니다.
  4. 각 행의 마지막 열에 **[본문가기]** 버튼(`QPushButton`)을 동적으로 생성하고, 클릭 시 해당 뉴스의 ID를 넘겨주는 람다(`lambda`) 함수를 연결합니다.

### ② `ShowTheMainNews(self, row)` — 상세 본문 불러오기
* **작동 순서**:
  1. 표에서 **[본문가기]** 버튼을 누르면 해당 뉴스의 고유 번호(`newsnumber`)가 인자로 전달됩니다.
  2. `mainnews` 테이블에서 고유 번호에 해당하는 본문 텍스트(`main`)를 가져옵니다.
  3. 가져온 텍스트를 `textBrowser`에 출력하여 화면 하단에서 바로 읽을 수 있게 합니다.

### ③ `SecondWindow(self)` — 웹 링크 연결 창 띄우기
* **작동 순서**:
  1. 사용자가 본문을 먼저 선택했는지 검사합니다.
  2. 해당 뉴스의 원본 웹 Link URL을 DB에서 조회합니다.
  3. 서브 창(`MyWindow2`)에 URL 데이터를 전달(`set_data`)하고, 메인 창을 숨긴 뒤 서브 창을 화면에 띄웁니다.

### ④ `open_web_site(self)` — 기본 브라우저로 원문 열기
* 서브 창에서 링크 버튼을 누르면 파이썬 내장 모듈인 `webbrowser.open()`을 활용해 사용자의 PC 기본 웹 브라우저(크롬, 엣지 등)에서 해당 뉴스 페이지를 열어줍니다.
