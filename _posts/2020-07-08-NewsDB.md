## 1. 뉴스 데이터 크롤링 및 DB 저장 코드 (`crawler.py`)

네이버 뉴스 목록 및 본문을 수집하여 `news` 테이블과 `mainnews` 테이블에 각각 저장하는 스크립트입니다.

### 💡 주요 핵심 로직
* **페이지 수 자동 계산**: 입력받은 날짜와 카테고리의 마지막 페이지 번호를 알아내기 위해 `page=9999` 요청 후 페이징 번호를 파싱합니다.
* **정규표현식(Regex) 활용**: 기사 URL에서 고유 식별 번호(`newsnumber`) 및 날짜 정보를 정규표현식(`re.search`)으로 추출합니다.
* **관계형 DB 저장**: 메인 데이터는 `news` 테이블에, 긴 본문 데이터는 `mainnews` 테이블에 각각 구분하여 저장합니다.

        newsname_str = newsname.text.strip() if newsname else "제목 없음"
        newsdate_str = newsdate.text.strip() if newsdate else "날짜 없음"

                name = newsname.text.strip()
                nurl = urlnews
                contentext = content_raw.strip()
                newi = newsome

                    sql = "INSERT INTO news (newsday, comname, newsname, Category, url, ownday, newsnumber, day) VALUES (%s, %s, %s, %s, %s, %s, %s, %s);"
                    
                    date_str = ""

                    if match:

                    data = (date, com, name, sid2, nurl, day, newi, date_str)
                    cursor.execute(sql, data)

                    # mainnews 테이블에 본문 저장
                    sql = "INSERT INTO mainnews (newsnumber, main) VALUES (%s, %s);"
                    data_child = (newi, contentext)
                    cursor.execute(sql, data_child)

                conn.commit()
            finally:
                print('데이터베이스 저장 완료')

    numberk += 1
    if numberk > last:
        conn.close()
        break

## 2. KoNLPy 및 KnuSentiLex 기반 뉴스 감성 분석 코드 (`sentiment_analysis.py`)

DB에 수집된 뉴스 본문에서 명사를 추출한 뒤, 군산대 한국어 감성사전(KnuSentiLex) 데이터와 비교하여 기사별 **감성 점수(Polarity)**를 계산하고 DB를 업데이트하는 코드입니다.

### 💡 주요 핵심 로직
* **KnuSentiLex 사전 로드**: GitHub에서 군산대 감성사전 JSON 데이터를 가져와 단어별 극성 점수(+2 ~ -2)를 딕셔너리로 저장합니다.
* **KoNLPy (Kkma) 명사 추출**: `Kkma.nouns()` 형태소 분석기를 이용해 뉴스 본문에서 명사 단어들만 걸러냅니다.
* **점수 합산 및 일괄 업데이트**: 추출된 명사가 감성사전에 존재하는 경우 해당 점수를 누적합(`propertyPoint`)하여 `executemany` 방식으로 DB의 `polarity` 컬럼에 일괄 매핑합니다.

### 📜 Source Code

```python
import json
import requests
import pymysql.cursors
from bs4 import BeautifulSoup
from konlpy.tag import Kkma

maintext = {}
parsedlist = {}
UpdateData = []

# 1. KnuSentiLex 감성사전 JSON 데이터 가공
response = requests.get('https://raw.githubusercontent.com/park1200656/KnuSentiLex/master/data/SentiWord_info.json')
html = response.text
soup = BeautifulSoup(html, 'html.parser')
parsed_list = json.loads(soup.text)

# 감성 사전 딕셔너리 구성 {단어: 극성점수}
for item in parsed_list:
    word = item["word"]
    polarity = item["polarity"]
    parsedlist[word] = int(polarity)

# 2. 형태소 분석기(Kkma) 및 DB 연결 설정
kkma = Kkma()
conn = pymysql.connect(
    host='183.100.182.169',
    user='root',
    password='swhacademy!',
    db='Suhyeon',
    charset='utf8'
)

try:
    with conn.cursor() as cursor:
        # DB에서 뉴스 본문 전체 가져오기
        sql = 'SELECT n.newsnumber, m.main FROM news n INNER JOIN mainnews m ON n.newsnumber = m.newsnumber;'
        cursor.execute(sql)
        result = cursor.fetchall()

        # 각 본문에서 명사(Noun) 추출
        for a4 in range(len(result)):
            news_id = result[a4][0]
            main_content = result[a4][1]
            noun = kkma.nouns(main_content)
            maintext[news_id] = noun

        # 3. 명사 단어별 감성 점수 계산
        for news_id, nouns in maintext.items():
            propertyPoint = 0
            for k in nouns:
                if k in parsedlist:
                    d = parsedlist[k]
                    propertyPoint += d

            # (감성점수, 뉴스번호) 튜플 형태로 저장
            UpdateData.append((propertyPoint, news_id))

        # 4. DB 일괄 업데이트 실행 (executemany)
        sql = 'UPDATE news SET polarity = %s WHERE newsnumber = %s;'
        cursor.executemany(sql, UpdateData)
        conn.commit()

finally:
    if conn:
        conn.close()
        print("데이터베이스 연결이 안전하게 종료되었습니다.")
```
